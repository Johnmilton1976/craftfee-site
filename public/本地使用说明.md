# CraftFee — 本地站点使用说明

## 这是什么

一个完整的出海垂直站（英文），主题：**Etsy 卖家费用计算器 + 费用指南**。
纯静态 HTML，共 12 个文件、174KB，不需要数据库、不需要 Node、不需要构建。

## 一、在本地打开（两种方式任选）

**方式 A：双击 `start-preview.bat`**（Windows）
自动打开浏览器，地址是 http://127.0.0.1:8787/ 。关掉黑窗口即停止。

**方式 B：命令行**
```bash
cd etsy-fee-site
sh start-preview.sh        # Git Bash / macOS / Linux
```

> 注意：本地预览用的 8787 端口如果被占用，脚本会自动换下一个端口，以窗口里显示的地址为准。

## 三、站点里已内置的东西

- **`_headers`**：Cloudflare Pages 的安全响应头 + 静态资源缓存策略（部署后自动生效）
- **`robots.txt` / `sitemap.xml`**：给搜索引擎用
- **`assets/og-image.png`**：1200×630 社交分享图（链接被转发到 X/Facebook/WhatsApp 时显示）
- **全站 OG 标签**：每页都有 `og:title / og:description / og:image / twitter:card`
- **结构化数据**：首页 WebSite、计算器 WebApplication、指南页 FAQPage
- **两处灰色 "ADVERTISEMENT" 虚线框**：预留的广告位，上线接 AdSense 时替换

## 四、上线前唯一必做的事

**换域名占位符。** 站内所有 canonical / sitemap / OG 链接都写着 `your-domain.com`。
买好域名后，在 `etsy-fee-site` 的上一级目录运行：

```bash
python set-domain.py 你的域名.com     # 一键替换全部占位符
python set-domain.py                  # 只检查不修改
python set-domain.py --revert         # 改回占位符
```

另外 `hello@your-domain.com`（About 页的纠错邮箱）也会被一并替换成你的域名邮箱。

## 五、完整部署步骤

见《部署操作清单.md》（买域名 → Cloudflare Pages → Google Search Console，约 1 小时）。

## 六、以后怎么改

- **改样式**：`assets/style.css`（全站共用一份）
- **改计算逻辑**：`assets/calculator.js` 顶部 `RATES` 表（每国费率都在这里）
- **加新页面**：复制任一内容页目录，改 `<title>`、`<meta description>`、canonical、正文，再把它加进首页 hub、robots 和 sitemap
- **费率变了**：改 `calculator.js` 的 RATES + 各页正文里的数字（正文里的例题数字和计算器实算是一致的，改一处别忘了另一处）
