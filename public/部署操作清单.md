## 二、上线前必须做的替换（用脚本，别手改）

所有文件里的域名占位符 `https://your-domain.com` 共 **60 处**（含社交分享标签），分布在 13 个 html + robots.txt + sitemap.xml 里。

**别手动替换**，用我给你写好的脚本（在 `etsy-fee-site` 的**上一级**目录）：

```bash
# 先看一眼还剩多少处没换
python set-domain.py

# 换成你的域名（不用写 https://）
python set-domain.py etsyfeecalc.com

# 换错了想改回来（本地重新测试用）
python set-domain.py --revert
```

**为什么必须换**：每个页面 `<head>` 里的 `canonical` 是告诉谷歌"这个页面的正式网址"。如果它指向别人的域名，谷歌会认为你的页面是重复内容，**不给排名**。

**换完之后（因为已连 GitHub）**：把改动提交并推送到仓库，Cloudflare 会自动重建：

```bash
cd etsy-fee-site
git add -A && git commit -m "Set real domain"
git push
```

> 顺序建议：**先买域名 → 跑 set-domain.py → 推送 → 再绑域名**。这样上线第一刻站点里的网址就是对的。

## 三、买域名（约 10 分钟）

1. 打开 **https://www.cloudflare.com** → 注册账号（邮箱 + 密码，免费）
2. 左侧菜单 → **Domain Registration** → **Register Domain**
3. 想一个名字。**不要带 `etsy`**（详见下面避坑）。建议纯描述词，例如：
   - `craftfee.com`（9 字母，最短最干净，craft=手作）
   - `makerfee.com`（8 字母最短；Etsy 生态里卖家自称 maker）
   - `craftfees.com` / `makerfees.com`（复数更顺口）
   - 已被占用的不用试：`sellerfeecalc` / `sellerfees` / `feecalculator` / `feecalc` / `feefinder` / `feechecker` 等（简短好词基本被抢完）
4. 搜一下，能买就买。**Cloudflare 按成本价卖域名（$10.44/年，注册=续费），续费不涨价**（这点比 GoDaddy 好很多）
5. 付款（支持信用卡/PayPal；如果没有，就去 **Spaceship** 或 **Porkbun** 买，同样便宜）

**避坑（重要）**：**域名 / 站名 / logo 里都不要出现 `etsy`。** Etsy 是注册商标，`etsyfees.com` 这类域名有**域名仲裁**风险——你一分钱没赚，对方一封律师函零成本，域名就可能被强制转走。注意区分：

| 用在哪 | 能不能用 etsy | 为什么 |
|---|---|---|
| 域名 / 站名 / logo | ❌ 不要 | 商标风险，可能被强制收回 |
| 页面内容、URL 路径（如 `/etsy-fees-uk/`） | ✅ 可以 | 属于描述性使用，风险很低（站内现有路径无需改） |

**域名不必包含关键词** —— 谷歌排名基本不看域名，域名的价值在"好记、好念、像品牌"。所以 `craftfee.com` 比 `craftfeecalculator.com` 更好。

## 四、部署到 Cloudflare Pages（约 30 分钟）

> ⚠️ **不要用 Vercel 免费版**。Vercel 的免费（Hobby）计划官方条款明确禁止商用，挂 AdSense 就算违规，被查到直接封号且不给申诉。Cloudflare Pages 免费版**允许商用、带宽无限**。

### 方式 A：从 GitHub 仓库部署（推荐 —— 代码已经在仓库里了）

**前提已完成**：代码已推送到 `https://github.com/Johnmilton1976/craftfee-site`（main 分支，24 个文件，含 `_headers`／`robots.txt`／`sitemap.xml` 全部在根目录）。

1. 登录 Cloudflare → 左侧 **Workers & Pages** → **Create** → 选 **Pages** → **Connect to Git**
2. 授权 GitHub（选 "Only select repositories" → 勾 `craftfee-site`，比给全部权限安全）
3. 选中 `craftfee-site` → **Begin setup**
4. 构建设置这样填（**关键：这是纯静态站，不需要任何构建**）：
   - Framework preset：**None**
   - Build command：**留空**
   - Build output directory：**`/`（留空或填 `/`）**
   - 根目录（Root directory）：留空
5. 点 **Save and Deploy** → 等 30 秒 → 得到一个免费网址 `craftfee-site.pages.dev`。**打开能看到计算器就算成功。**
6. 部署成功后再点 **Continue to project**（这一步 Cloudflare 有时会漏提示）

**连上之后的好处**：以后改东西，只要把新代码推到 GitHub，Cloudflare 自动重新发布——**不用登录 Cloudflare 后台，也不用再拖文件夹**。

### 方式 B：直接上传（不用 Git，最省事）

1. 登录 Cloudflare → 左侧 **Workers & Pages** → **Create** → **Pages** → **Upload assets**
2. Project name 填 `craftfee-site`
3. 把 `etsy-fee-site` 文件夹**里面的内容**拖进去（要保证 `index.html` 在根目录，别把整个文件夹套一层）
4. 点 **Deploy** → 得到 `craftfee-site.pages.dev`

### 方式 C：绑定你的域名

1. 进入刚建的项目 → **Custom domains** → **Set up a custom domain**
2. 输入你买的域名（如 `craftfee.com`），点继续
3. 如果域名就是在 Cloudflare 买的，会自动配好。等 1–2 分钟生效
4. 访问你的域名，能看到站点 → **恭喜，你有一个真网站在线了**

### 方式 D：以后怎么更新

- **连了 GitHub（方式 A）**：改本地文件 → 提交并推送到 GitHub → Cloudflare 自动重建。30 秒～2 分钟生效
- **用直传（方式 B）**：改完文件 → 回到项目 → **Create new deployment** → 重新拖一次文件夹

> ⚠️ **更新的唯一红线：不要改已有页面的 URL。** 改 URL 等于开了一个全新页面，之前攒的收录和排名全部归零；真要改必须配 301 重定向。

## 五、提交给搜索引擎（约 15 分钟）

### Google Search Console

1. 打开 **https://search.google.com/search-console**
2. 添加资源 → 选**网域** → 输入你的域名 → 验证（Cloudflare 买的域名可以一键 DNS 验证，或选 HTML 标签方式，把标签贴进 index.html 的 `<head>`）
3. 验证通过后 → 左侧 **Sitemaps** → 输入 `sitemap.xml` → 提交
4. 左侧 **URL 检查** → 输入你的首页网址 → 点**请求编入索引**

**这一步只是"报名"，不是"录取"。** 提交 ≠ 收录 ≠ 有排名。

### Bing 也一样

**https://www.bing.com/webmasters** → 可以直接从 GSC 导入站点，2 分钟搞定。

## 六、什么时候申请 AdSense（别急）

**不要在站刚上线、还没流量的时候申请**，通过率很低。建议顺序：

1. 站点上线，至少有 10 个页面（现在已经有）
2. 等谷歌**收录**（几天到几周，在 GSC 的"页面"报告里能看到）
3. 有了一点点自然访问（GSC 显示有展示/点击）
4. 这时再申请 **https://adsense.google.com**

申请通过后，把 AdSense 给的代码贴到页面上写着 `ADVERTISEMENT` 的灰框位置（每个页面有 1–2 处）。

**收款准备**（提前做，别等有钱了才发现取不出来）：

- 满 $100 才起付
- 需要 PIN 平信验证真实地址（寄到你家/公司，别填错）
- 填 W-8BEN 税表（中国居民预扣 0%）
- 提现通道：招行电汇（最稳，占个人每年 $5 万结汇额度）或 Payoneer / 万里汇（新手省心，费率 0.3%–1%）
- **这笔是境外所得，依法要申报个税**

## 八、已验证的事实清单（免得走弯路）

- ✅ Cloudflare Pages 免费版允许商用，带宽无限，单文件上限 25MB
- ❌ Vercel Hobby 免费版禁止商用（"monetizing in any way"），挂广告违规
- ✅ 一个 AdSense 账号可以管多个站（但一损俱损，单站违规可能波及账号）
- ✅ 免费子域名 `xxx.pages.dev` 能跑，但 AdSense 审核更严、且不算资产（卖不掉）
- ✅ **算得准就是本站护城河**，具体这几条是竞品普遍做错的：
  1. 三项费用**基数不同**：6.5% 不含税、processing 含税、监管费不含税
  2. **Offsite Ads 按订单总额（含运费）算**，且有 US$100/单上限
  3. **监管运营费各国不同、2026-06-22 刚大改**：法 1.14%、匈 1.97%、意 0.80%、西 0.88%、加 0.50%、英 0.48%；美/德/澳/新西兰**没有**
  4. **加拿大、澳洲的支付费率分境内/境外两档**（境内 3%，境外 4%）——计算器已支持切换
  5. 欧洲 VAT 要从含税价里**剥出来**，不能当收入
  6. 挂牌币种 ≠ 收款币种时另有 **2.5% 换汇费**

**本地验收结果**（2026-10-12 实测，无头浏览器渲染）：
- 10 个页面全部返回 200，控制台零报错、零请求失败
- 17 组计算断言全部与文章正文数字一致（美国默认 $38：费用 $4.06 / 到手 $33.94 / 有效费率 10.7%）
- 反算模式：想净落 $30 → 应标 $33.65 ✓

## Changing a social/OG image (og-image, favicon)

`/assets/*` is served `immutable, max-age=1 year`, and social crawlers (WeChat,
Facebook, X) cache the card by URL. A `?v=N` query does not help them.

**So: when the image content changes, rename the file** (e.g.
`og-image.png` → `og-image-craftfee.png`) and update every `og:image` /
`twitter:image` reference — all 15 pages plus `seo_build.py`. Never overwrite
an OG image in place.
